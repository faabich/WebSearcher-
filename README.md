# WebSearcher++

This is a web searcher application built with Python, reflex UI framework and the DuckDuckGo Search API

# Description
Application web basée sur des recherches web avancées sur plusieurs moteurs de recherche. <br>
**Use case**: Le champ d'application est sur tout les utilisateurs souhaitant faire des recherches sur le web.

# Installation
1. clone repository:
```bash
git clone
```
2. install dependencies:
```bash
pip install -r requirements.txt
```

# Run the application
1. to run the WebSearcher++ application, run the following command:
```bash
reflex run
```

# Pré-requis
* DataBase Engine: MangoDB
* Web Framework: Reflex
* IDE used: JetBrains PyCharm
* Package manager: pip
